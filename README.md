# 🚀 Space Shooter Pro

Welcome to my portfolio! This is a 2D Space Shooter game I developed in Unity to practice core game mechanics, player movement, and enemy spawning.

***

### 🎮 **CLICK THE SCREEN BELOW TO PLAY THE GAME!**

[![spaceshooterpro](https://github.com/user-attachments/assets/2fe85ac3-fd34-4222-a6ed-bac6bc04347a)](https://aurangzaib-gr.github.io/Space-Shooter-Pro/)
> **Note:** The game runs directly in your browser. No downloads needed!

## 🕹️ How to Play
* **Arrow Keys / WASD:** Move your spaceship
* **Spacebar:** Shoot lasers
